# 🚀 Quick Start Guide - Fee Management System

## ⚡ 5-Minute Setup

### Step 1: Install AG-Grid (1 minute)
```bash
cd "d:\Projects\School Managment System Offline First\Client"
npm install ag-grid-react ag-grid-community
```

### Step 2: Start Backend (30 seconds)
```bash
cd "d:\Projects\School Managment System Offline First\backend"
npm run dev
```

### Step 3: Start Frontend (30 seconds)
```bash
cd "d:\Projects\School Managment System Offline First\Client"
npm run dev
```

### Step 4: Login (30 seconds)
- Open: http://localhost:5173
- Email: `admin@school.af`
- Password: `admin123`
- Click: ننوتل

### Step 5: Test Fee Management (2 minutes)
1. Click "عاید او فیسونه" in sidebar
2. Click "نوی فیس" button
3. Enter student ID: 1
4. Fill form and submit
5. See auto-print receipt

**Done! ✅**
