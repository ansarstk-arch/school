Problem: "Cannot connect from phone/tablet"
Solution: 
  1. Make sure device is on SAME WiFi
  2. Check server is running (window is open)
  3. Try: http://192.168.43.215:3000
  4. Check Windows Firewall (may need to allow port 3000)

Problem: "Port 3000 already in use"
Solution: 
  1. Close any running server windows
  2. Restart your computer
  3. Run START_SERVER.bat again

Problem: "URL not working after restart"
Solution:
  If your PC's WiFi IP changes, you may need to update the URL.
  Check new IP with: ipconfig (look for IPv4 Address under WiFi)
