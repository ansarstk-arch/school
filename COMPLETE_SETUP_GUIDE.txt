⚙️ RECOMMENDED SETTINGS FOR SERVER PC:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Disable Sleep Mode:
   Settings > System > Power & sleep > Never

2. Keep PC Plugged In:
   Don't run on battery

3. Enable Auto-Login (Optional):
   netplwiz > Uncheck "Users must enter password"

4. Allow Port 3000 in Firewall:
   See: FIREWALL_SETUP.txt (if devices can't connect)

5. Static IP (Optional but recommended):
   Network Settings > Set manual IP: 192.168.43.215

💾 BACKUP INSTRUCTIONS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Database Location:
  backend/database/school.db

How to Backup:
  1. Stop server (STOP_SERVER.bat)
  2. Copy backend/database/school.db
  3. Paste to USB drive or external hard disk
  4. Rename with date: school_backup_2026-06-04.db
  5. Restart server

Backup Schedule:
  • Daily: If data changes frequently
  • Weekly: For normal use
  • Monthly: Archive old backups


🔧 TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Can't access from phone
Solution:
  ✓ Check same WiFi network
  ✓ Run CHECK_SERVER_STATUS.bat
  ✓ Check Windows Firewall (see FIREWALL_SETUP.txt)
  ✓ Verify IP: Run CHECK_IP_ADDRESS.bat

Problem: Server not starting on boot
Solution:
  ✓ Run INSTALL_AUTO_START.bat again
  ✓ Check Task Manager for node.exe
  ✓ Try manual start: START_SERVER.bat

Problem: IP address changed
Solution:
  ✓ Run CHECK_IP_ADDRESS.bat
  ✓ Update URL with new IP
  ✓ Or set static IP in router settings

Problem: Slow performance
Solution:
  ✓ Close other programs on server PC
  ✓ Check WiFi signal strength
  ✓ Restart server and router
