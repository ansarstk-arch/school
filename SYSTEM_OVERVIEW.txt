💡 TIPS FOR BEST PERFORMANCE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Use a dedicated PC for the server (not for gaming/other work)
2. Keep the PC plugged in (not on battery)
3. Disable sleep mode on server PC
4. Use good WiFi router (for stable connections)
5. Keep server PC in cool, clean environment


📞 TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: Can't connect from other devices
Fix: 
  - Check same WiFi network
  - Run FIREWALL_SETUP.txt steps
  - Verify server is running

Issue: Slow performance
Fix:
  - Close other programs on server PC
  - Check WiFi signal strength
  - Restart server

Issue: Data not saving
Fix:
  - Check disk space on server PC
  - Verify database file permissions
  - Restart server
