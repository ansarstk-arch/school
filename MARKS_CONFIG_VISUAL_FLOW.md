## Validation Flow

```
User enters value
       ↓
Client-side validation
       ↓
   ┌───────┐
   │ Valid? │
   └───┬───┘
       │
   ┌───┴───┐
   │       │
  Yes     No
   │       │
   │       └→ Show error message below field
   │          Error clears when user types
   │
   ↓
User clicks "Save All"
   ↓
Validate all fields
   ↓
   ┌───────┐
   │ Valid? │
   └───┬───┘
       │
   ┌───┴───┐
   │       │
  Yes     No
   │       │
   │       └→ Toast: "مهرباني وکړئ ټولې تېروتنې سمې کړئ"
   │          Highlight all errors
   │
   ↓
Send to server
   ↓
Server-side validation
   ↓
   ┌───────┐
   │ Valid? │
   └───┬───┘
       │
   ┌───┴───┐
   │       │
  Yes     No
   │       │
   │       └→ Return error message
   │          Show toast with error
   │
   ↓
Save to database
   ↓
Return success
   ↓
Toast: "بریالي ثبت شو"
   ↓
Close modal
   ↓
Refresh table
```
