First Time Setup:
  1. Read: ⭐_START_HERE.txt
  2. Run: INSTALL_AUTO_START.bat (for auto-start)
     OR
     Run: START_SERVER.bat (for manual start)
  3. Access: http://localhost:3000

Daily Use (with auto-start):
  1. Turn on PC
  2. System starts automatically
  3. Use immediately!

Daily Use (without auto-start):
  1. Double-click: START_SERVER.bat
  2. Access the system
  3. Close window when done
