# Attendance Download Feature - User Guide

## Student Attendance Download

### Step-by-Step Instructions:

1. **Navigate to Student Attendance**
   - Go to: حاضري → د زده کوونکو حاضري

2. **Scroll to Download Section**
   - Look for "د حاضرۍ راپور ډاونلوډ" section (with download icon)

3. **Select Filters:**
   - **د ادارې ډول (Institution Type)**: Choose School, Center, or Madrasa
   - **ټولګی (Class)**: Select the class you want to download
   - **د راپور موده (Report Period)**: Choose:
     - ورځنی (Daily) - Today's attendance
     - میاشتنی (Monthly) - Current month
     - کلنی (Yearly) - Current year
   - **نېټه (Date)**: Adjust start and end dates if needed

4. **Download:**
   - Click **Excel ډاونلوډ** for Excel file (.xlsx)
   - OR Click **PDF ډاونلوډ** for PDF file (.pdf)

5. **File Opens Automatically**
   - File will download to your browser's download folder

## Staff Attendance Download

### Step-by-Step Instructions:

1. **Navigate to Staff Attendance**
   - Go to: حاضري → د کارمندانو حاضري

2. **Scroll to Download Section**
   - Look for "د حاضرۍ راپور ډاونلوډ" section (with download icon)

3. **Select Filters:**
   - **د راپور موده (Report Period)**: Choose:
     - ورځنی (Daily) - Today's attendance
     - میاشتنی (Monthly) - Current month
     - کلنی (Yearly) - Current year
   - **د پیل نېټه (Start Date)**: Adjust if needed
   - **د پای نېټه (End Date)**: Adjust if needed

4. **Download:**
   - Click **Excel ډاونلوډ** for Excel file (.xlsx)
   - OR Click **PDF ډاونلوډ** for PDF file (.pdf)

5. **File Opens Automatically**
   - File will download to your browser's download folder

## Report Contents

### Student Attendance Report Includes:
- Report header with filters applied
- Statistics: Total, Present, Absent, Leave counts
- Table with columns:
  - # (Number)
  - نوم (Name)
  - د پلار نوم (Father Name)
  - نمبر (Roll Number)
  - نېټه (Date)
  - حالت (Status) - Color coded:
    - 🟢 Green = Present (حاضر)
    - 🔴 Red = Absent (غیر حاضر)
    - 🟡 Yellow = Leave (رخصتي)
  - میتود (Method) - Manual or QR

### Staff Attendance Report Includes:
- Report header with date range
- Statistics: Total, Present, Absent, Leave counts
- Table with columns:
  - # (Number)
  - نوم (Name)
  - د پلار نوم (Father Name)
  - دنده (Position)
  - نېټه (Date)
  - حالت (Status) - Color coded
  - میتود (Method) - Manual or QR

## Tips

### Quick Downloads:
- **Today's Report**: Select "ورځنی" (Daily) and click download
- **This Month**: Select "میاشتنی" (Monthly) and click download
- **This Year**: Select "کلنی" (Yearly) and click download

### Custom Date Range:
1. Select any period first
2. Manually adjust the start and end dates
3. Click download

### Excel vs PDF:
- **Excel (.xlsx)**: 
  - Best for data analysis
  - Can be edited and filtered
  - Color-coded status cells
  - Can import into other software

- **PDF (.pdf)**:
  - Best for printing
  - Professional appearance
  - Cannot be edited
  - Smaller file size

## Troubleshooting

### "مهرباني وکړئ ټولګی غوره کړئ" (Please select a class)
- **Solution**: You must select a class before downloading student attendance

### "د ډاونلوډ کې ستونزه" (Download error)
- **Solution**: Check your internet connection and try again

### File doesn't download
- **Solution**: 
  1. Check if pop-ups are blocked in your browser
  2. Allow pop-ups for this website
  3. Try again

### Empty report
- **Solution**: No attendance records exist for the selected filters. Try:
  - Different date range
  - Different class
  - Check if attendance was actually recorded

## File Naming Convention

Downloaded files are named automatically:
- Format: `attendance_[Type]_[StartDate]_[EndDate].[ext]`
- Examples:
  - `attendance_Student_2024-01-01_2024-01-31.xlsx`
  - `attendance_Staff_2024-01-15_2024-01-15.pdf`
